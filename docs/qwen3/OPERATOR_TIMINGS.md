# 已测到的算子与区间耗时

数据来自2026-10-26实际QCS9075板测，Qwen3-0.6B完整28层、batch=1、query=8、KV容量1024。这里重新整理已有原始计数，没有新增板测。

未插桩DSP模型内核为6.726秒。低开销时间线版本为6.906秒，观测开销约2.7%。下面两表均来自同一时间线的两次完整模型观测取均值，完全排除模型编译与加载。

## 完整时间线

| 计算部分 | 合计秒数（28层） | 占时间线比例 |
| --- | ---: | ---: |
| QK前处理与QK相关区间 | 2.972 | 43.0% |
| Softmax首个至末个指数调用之间 | 0.310 | 4.5% |
| PV及后处理相关区间 | 2.508 | 36.3% |
| 全部INT8矩阵乘 | 0.583 | 8.4% |
| 其余区间 | 0.534 | 7.7% |
| 合计 | 6.906 | 100.0% |

前3行合计5.789秒，占83.8%。QK前区间还包含Q/K归一化、RoPE、KV更新、布局处理和guard中的适用部分；PV后区间还包含Softmax收尾和布局处理。因此 **QK、完整Softmax、PV的独立算子耗时尚未测出**，不能把这些区间直接改名为单个算子。RMSNorm和完整SiLU的独立耗时也没有闭合。

| 实际调用 | 调用次数 | 总秒数 | 占完整时间线比例 |

| K投影 INT8矩阵乘 | 28 | 0.0237 | 0.34% |
